# @ticora/devtools

[![npm](https://img.shields.io/npm/v/%40ticora%2Fdevtools)](https://www.npmjs.com/package/@ticora/devtools) [![license](https://img.shields.io/npm/l/%40ticora%2Fdevtools)](../../LICENSE)

Devtools panel for inspecting specs, queries, and verdicts.

See exactly why a spec was refused, mid-development.

## Install

```sh
npm install @ticora/devtools
```

## Use

```tsx
import { WorkspaceDevtools } from "@ticora/devtools";

<WorkspaceDevtools />  // mount alongside your provider in development
```
